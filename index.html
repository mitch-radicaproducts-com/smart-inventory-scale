Connection

Chrome has to open the USB serial adapter itself. A barcode scanner types because it pretends to be a keyboard. This scale does not.

How this scale sends

  1. Connect a USB-to-RS232 adapter. The scale transmits on pin 2, receives on pin 3, and uses pin 5 for ground. This model’s manual does not draw the plug. Those pins are from the same seller’s other balances.
  2. On the scale, press 7, 8, 9 until diu, then PCS/SET until bud. Confirm 9600 with Alarm. PCS/SET to odE, then Alarm. Choose 1, 2, or 3 and press Alarm. Turn the scale off and on.
  3. Mode 1 sends when you press P. Mode 2 sends when the weight settles. Mode 3 keeps sending. The page only listens. Writing a command does not request a reading.

The manual does not show a sample print. Last print is the text that arrived. Weight, pieces, and unit weight fill in only when that text names them. A bare number does not get a unit added.
